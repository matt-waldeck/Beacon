v0.3.3 (2026-10-18)
-Lots of bugs squashed.
    -Changing the URL hash (for example opening #apps) while still signed out or loading threw a page error. It’s now harmless.
    -Data responses that arrived after you signed out are ignored instead of redrawing the page.
    -Leaving the Apps tab while in Edit layout mode no longer leaves you stuck, since the button is hidden there. It now exits edit mode.
    -COOKIE_SECURE=0 and TRUST_PROXY=0 used to switch those options on, because any non-empty value counted. Only 1, true, yes and on do now.
-Reworked Pastel theme.
-Improved mobile friendliness.
-Added /healthz check for Portainer.

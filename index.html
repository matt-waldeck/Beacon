Beacon remembers each device's SSH key the first time it connects and refuses to connect if the key changes. After resetting or replacing a device, forget its key so it is trusted again.

Configure UniFi sites


Add each UniFi Network application Beacon should read devices from. Create an API key in that application under Settings > Control Plane > Integrations. Keys are kept on the server and never sent back to the browser.

Configure destinations


Add each place Beacon should send messages to: a webhook, or an email through your own mail server. Beacon doesn't deliver mail itself. Webhook addresses and passwords are kept on the server and never sent back to the browser.











Forget SSH host keys


A forgotten device is trusted again the next time Beacon connects to it, so only do this for devices you reset or replaced, on a network you trust.
